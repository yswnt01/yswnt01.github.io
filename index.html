Excel formulas I've written

Day TAT

Used in the CET daily report. Counts the days from pickup (S) to handover (T), skips any dates in the Holiday list sheet, and never returns less than 0.

=IF(IFERROR(TEXT(T3,"DD-MMM-YY")-TEXT(S3,"DD-MMM-YY")-COUNTIFS('Holiday list'!A:A,">="&S3,'Holiday list'!A:A,"<="&T3),0)<=0,0,IFERROR(TEXT(T3,"DD-MMM-YY")-TEXT(S3,"DD-MMM-YY")-COUNTIFS('Holiday list'!A:A,">="&S3,'Holiday list'!A:A,"<="&T3),0))

Time TAT

Used in the same report. Calculates the working hours from pickup to handover. A work day runs 10:00 AM to 7:00 PM, or to 4:30 PM on Saturdays. It returns 0:00 when a time is missing or the result is negative.

=IF(OR(S3="",T3=""),TIME(0,0,0),IF(IF(TEXT(S3,"DDDD")="Saturday",IF(U3<=0,TEXT(T3,"HH:MM:SS")-TEXT(S3,"HH:MM:SS"),(TIME(16,30,0)-TEXT(S3,"HH:MM:SS"))+(TEXT(T3,"HH:MM:SS")-TIME(10,0,0))),IF(U3<=0,TEXT(T3,"HH:MM:SS")-TEXT(S3,"HH:MM:SS"),(TIME(19,0,0)-TEXT(S3,"HH:MM:SS"))+(TEXT(T3,"HH:MM:SS")-TIME(10,0,0))))<=0,TIME(0,0,0),IF(TEXT(S3,"DDDD")="Saturday",IF(U3<=0,TEXT(T3,"HH:MM:SS")-TEXT(S3,"HH:MM:SS"),(TIME(16,30,0)-TEXT(S3,"HH:MM:SS"))+(TEXT(T3,"HH:MM:SS")-TIME(10,0,0))),IF(U3<=0,TEXT(T3,"HH:MM:SS")-TEXT(S3,"HH:MM:SS"),(TIME(19,0,0)-TEXT(S3,"HH:MM:SS"))+(TEXT(T3,"HH:MM:SS")-TIME(10,0,0))))))

Conveyance report lookup

Used in the conveyance report that goes to the CEO every month. For PayMT rows, it looks up the earlier row with the same reference (P) and the opposite amount (C), then returns that row's value from column H. Other rows stay blank.

=IF(G2="PayMT",
IFERROR(
INDEX(H$1:H1,
MATCH(1,
(P$1:P1=P2)*(C$1:C1=-C2),
0)
),
""),
"")
